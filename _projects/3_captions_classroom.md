Automatic captioning systems are tuned and benchmarked on clean speech: one speaker, no background noise, common vocabulary. Classrooms are nothing like that — multiple speakers interrupt each other, instructors use field-specific jargon, and many students are non-native speakers of the language being captioned.

This project measures how off-the-shelf real-time captioning systems perform in those conditions, and prototypes interfaces that show the *reader* when the captions are likely to be wrong.

**What students do.** Collect or curate classroom audio (with permission), run several captioning systems side-by-side, compute and compare error rates, and prototype UI alternatives.

**Skills you might build.** Audio processing, transcript alignment, error metric computation, front-end prototyping (React or similar).
